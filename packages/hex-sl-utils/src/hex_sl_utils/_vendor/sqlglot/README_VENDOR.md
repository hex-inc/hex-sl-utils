# Vendored sqlglot

This directory contains a vendored copy of sqlglot version v27.8.0.

Original repository: <https://github.com/tobymao/sqlglot>

## How to update

Run the vendoring script:

```bash
just build-vendoring
```

This will download sqlglot and update all imports.
